FlowTech V17 — ابدأ من هنا

1) ثبّت المتطلبات:
   pkg install git unzip nodejs-lts -y

2) ثبّت مكتبات المشروع:
   npm install

3) شغّل:
   npm start

4) افتح لوحة التحكم:
   http://localhost:3000

5) الربط:
   استخدم «ربط واتساب» ثم أدخل الرقم الدولي واطلب رمز الربط.
   طريقة الربط محفوظة من V7 ولا تعتمد على QR في لوحة التحكم.

6) AI:
   - أدخل رقم حساب واتساب الذي سيشغل الذكاء.
   - اختر Gemini.
   - النموذج الافتراضي: gemini-3.8-flash.
   - أدخل مفتاح API.
   - فعّل الرد الآلي.
   - اضغط «حفظ إعداد AI».
   - المفتاح يبقى محفوظًا ويظهر في الحقل بعد الحفظ.
   - الرسائل التي تبدأ بنقطة تبقى أوامر ولا يجيب عليها AI.
   - الرسائل العادية بدون نقطة هي التي يعالجها AI.
   - إذا كان إعداد AI واحد فقط مفعّلًا، يستخدمه البوت كإعداد افتراضي عند عدم وجود إعداد مطابق للمرسل.

7) الحماية:
   استخدم .أوامر_المجموعة أو .كل_الأوامر لعرض الأوامر في رسالة واحدة.

ملاحظة: ملفات session وdata/settings.json لا تُحذف أثناء تحديث المشروع إلا إذا حذفتها بنفسك.

# FlowTech V32.1

بوت واتساب مع لوحة تحكم لإدارة الربط والإعدادات والأوامر.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm start
```

تبدأ نقطة التشغيل من `index.js` وتبقى تفاصيل التطبيق في `src/` وملفات الواجهة في `public/`. ملف `Procfile` يستخدم `npm start` على Heroku.

## Heroku وMongoDB Atlas

1. ارفع ملفات المشروع إلى Heroku وانشره باستخدام Node.js buildpack.
2. من Settings → Config Vars أضف `MONGODB_URI` بقيمة رابط Atlas الحقيقي. استبدل خانات اسم المستخدم وكلمة المرور في الرابط ببيانات قاعدة البيانات، وشفّر الرموز الخاصة في كلمة المرور URL-encoding. لا تحفظ الرابط السري في Git أو ZIP.
3. أضف `MONGODB_DB_NAME=flowtech`.
4. أضف `DASHBOARD_SECRET` بقيمة طويلة وعشوائية، أو استخدم مولّد الأسرار في إعدادات Heroku.
5. تحقق من إعداد Network Access وصلاحيات مستخدم MongoDB، ثم راجع Heroku Logs للتأكد من اتصال قاعدة البيانات.
6. شغّل نسخة واحدة فقط لكل جلسة واتساب.

يدعم المشروع حفظ بيانات مصادقة Baileys ومفاتيح الجلسة في مجموعة `whatsapp_auth` عند ضبط `MONGODB_URI`. كما تتم مزامنة حسابات لوحة التحكم وإعداداتها. يجب اختبار استعادة الجلسة على الاستضافة الفعلية قبل الاعتماد عليها.

## الأوامر والوسائط

أرسل `.اوامر` لعرض الأقسام، ثم رقم القسم لعرض أوامره. لعرض القائمة الكاملة استخدم `.كل_الأوامر_الكاملة`.

- `.موسيقى اسم الأغنية`
- `.يوتيوب عبارة البحث`
- `.تحميل رابط`
- `.apk اسم التطبيق` للبحث في مستودع F-Droid الرسمي
- `.بلاي اسم التطبيق` للبحث في Google Play

تنزيل الوسائط يعتمد على وجود Python وFFmpeg وyt-dlp في بيئة التشغيل ودعم المصدر للمحتوى المطلوب.

## الملفات والبيانات

- `index.js`: نقطة التشغيل المناسبة لـ Heroku.
- `src/`: منطق الخادم والتخزين وواتساب والذكاء الاصطناعي.
- `public/`: لوحة التحكم والواجهة.
- `commands/catalog.js`: فهرس الأوامر والاختصارات في ملف مستقل. بقي تنفيذ الأوامر داخل مشغّل واتساب الأساسي للحفاظ على ترابط الصلاحيات والسياق وعدم كسر الأوامر عند النقل.
- `.env.example`: نموذج للإعدادات المحلية. ملف `.env` الحقيقي مستبعد من حزمة التسليم؛ أدخل القيم السرية في Config Vars على Heroku.

## تنظيم الملفات والهوية
- `commands/catalog.js`: أسماء الأوامر والاختصارات وفهرس الأقسام.
- `lib/branding.js`: إضافة توقيع FlowTech تلقائيًا إلى الرسائل النصية والتعليقات المصاحبة للوسائط.
- `src/`: تشغيل واتساب، الخادم، التخزين، الذكاء الاصطناعي، وMongoDB.
- `public/`: ملفات لوحة التحكم.

يُضاف التوقيع `『˼فلو تيك˹ ❘❘ ˼𝙵𝙻𝙾𝚆𝚃𝙴𝙲𝙷˹』` تلقائيًا إلى الردود النصية والتعليقات المصاحبة للصور والفيديو والملفات. واتساب لا يتيح فرض لون رمادي أو حجم خط مخصص على النص العادي؛ لذلك يظهر التوقيع كنص مزخرف عادي.

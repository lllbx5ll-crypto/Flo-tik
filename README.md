# FlowTech WhatsApp Bot v2

مشروع بوت واتساب حقيقي باسم **FLOWTECH | فلو تيك**، مبني على Node.js وBaileys.

## أهم ما تم تنفيذه

- اتصال WhatsApp Web حقيقي عبر Baileys.
- QR Code حقيقي + Pairing Code حقيقي.
- حفظ جلسة المصادقة داخل `session/` وإعادة اتصال تلقائية.
- لوحة تحكم Responsive للجوال والتابلت والكمبيوتر.
- لوحة التحكم افتراضيًا **بدون كلمة مرور** حسب الطلب (`DASHBOARD_AUTH=false`)؛ أي شخص يصل للرابط يستطيع فتحها.
- قوائم WhatsApp تفاعلية Native Flow + أزرار Quick Reply، مع fallback نصي إذا لم يدعم العميل الرسالة التفاعلية.
- أوامر عربية وإنجليزية وفرنسية.
- مشاهدة الحالات تلقائيًا ومحاولة التفاعل معها بإيموجي محدد من اللوحة.
- اختيار إيموجي الحالة: ❤️ 😂 🔥 😍 😮 😢 👏 أو أي إيموجي آخر.
- سجل حي لأحداث الحالات في لوحة التحكم.
- رد آلي بالذكاء الاصطناعي عبر OpenAI Responses API أو Gemini API.
- AI في الخاص، وفي المجموعات إما عند المنشن فقط أو كل الرسائل.
- حماية الروابط والكلمات + ترحيب + طرد/ترقية/خفض/تحذير/تاج للجميع.
- ثلاث شعارات FlowTech داخل `public/assets/`.
- رقم التواصل مضبوط على `967783943604`.

## التشغيل

```bash
npm install
npm start
```

ثم افتح المنفذ `3000` أو رابط الاستضافة.

## الربط الحقيقي

1. افتح لوحة التحكم.
2. ادخل إلى **الربط الحقيقي**.
3. استخدم QR أو Pairing Code.
4. لا تحذف مجلد `session` بعد نجاح الربط.
5. في الاستضافة استخدم Disk/Volume دائم حتى لا تضيع جلسة واتساب.

## الذكاء الاصطناعي

في `.env` اختر:

```env
AI_PROVIDER=gemini
GEMINI_API_KEY=ضع_المفتاح_هنا
GEMINI_MODEL=gemini-3.8-flash
```

أو:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=ضع_المفتاح_هنا
OPENAI_MODEL=gpt-5.5
```

ثم فعّل AI من لوحة التحكم.

## لوحة بدون كلمة مرور

هذا مقصود بناءً على طلب المشروع:

```env
DASHBOARD_AUTH=false
```

إذا كانت اللوحة على الإنترنت العام، يفضّل جدًا تشغيل الحماية:

```env
DASHBOARD_AUTH=true
ADMIN_PASSWORD=كلمة_مرور_قوية
```

لأن لوحة التحكم تحتوي على عمليات حساسة مثل طلب Pairing Code وفصل جلسة واتساب.

## ملاحظة مهمة عن الحالات

المشروع لا يحاكي شاشة الحالة؛ الكود يستمع لرسائل الحالات التي تصل إلى جلسة WhatsApp Web، ويحاول تسجيل المشاهدة ثم يرسل Reaction إلى مفتاح الحالة الحقيقي. دعم وتنسيق رسائل الحالات يتغير أحيانًا مع إصدارات واتساب/Baileys، لذلك لا يمكن ضمان أن كل نوع من الحالات سيُقبل التفاعل معه على كل إصدار من واتساب.

## الاختبار

تم فحص Syntax لملفات JavaScript داخل المشروع. لم يتم تسجيل رقم واتساب فعلي في بيئة البناء هنا، لذلك لا ندّعي أننا أجرينا ربطًا حيًا بحساب واتساب من داخل بيئة الإنشاء.
